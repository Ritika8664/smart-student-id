# smart-student-id
📇 Smart Student ID Generator built with React

A sleek and user-friendly web application built with ReactJS that allows students to generate their smart ID cards with key features like photo upload, allergy selection, QR code generation, ID preview, and PNG download.

---

 ✨ Features

- 🎓 Student Form – Collects name, roll number, class, division, rack number, allergies, and more.
- 🖼️ Photo Upload – Lets users upload and preview their photo on the ID card.
- 🚍 Dropdown Inputs – Easy selection for class/division and bus routes.
- 🌿 Allergies Multi-Select – Choose multiple allergies from predefined options.
- 📇 Live ID Card Preview – Shows a real-time preview of the smart ID.
- 🔳 QR Code Integration – Auto-generates a QR code with student details.
- 🎨 Template Switching – Choose different designs for the ID card.
- 💾 LocalStorage Support – Optionally saves recent cards.
- 📥 Download as PNG – Export the ID card as an image using `html-to-image`.

---

🚀 Tech Stack

- ReactJS
- JavaScript
- `qrcode.react` – QR code generator
- `html-to-image` – For downloading the ID as PNG
- CSS (basic)  
(TailwindCSS optional – can be added later for styling)

---

🧪 How to Use

1. Fill in all the required student details.
2. Upload a photo and select allergies and other dropdowns.
3. View the real-time generated smart ID card.
4. Switch template if desired.
5. Click "Download" to save the ID card as a PNG image.
